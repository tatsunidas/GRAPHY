# DICOM Viewer/Workstation

# Core Features

- DICOM I/O (Local DIMSE and WADO)
- PlugIn interface
- Minimum Local DB (Derby)
- 2D viewer
- 3D viewer
- MPR
- ROI analysis
- Burning CD/DVD (with WEASIS)
