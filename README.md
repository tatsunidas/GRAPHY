# DICOM Viewer/Workstation

# User Manual
https://tatsunidas.github.io/GRAPHY/

# Core Features

- DICOM I/O (Local DIMSE)
- PlugIn interface
- Minimum Local DB (Derby)
- 2D viewer
- 3D viewer
- MPR
- ROI analysis
- Burning CD/DVD (with WEASIS) ※windows only
