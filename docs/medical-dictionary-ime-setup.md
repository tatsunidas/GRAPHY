# 医療用語辞書(日本語)のIME登録手順

レポート作成時に、病名・所見語などの日本語医療用語を変換できるようにするための手順書です。
これらの用語は標準の日本語入力(IME)の辞書には含まれていないため、**医療用語辞書ファイル
(ご自身でご用意ください)**をお使いの IME に取り込む(ユーザー辞書登録する)必要があります。

> **GRAPHY は医療用語辞書を同梱しません。** 公開されている医療用語辞書や、自施設で作成した
> 用語リストを、お使いの IME の形式(セクション 7 の付録参照)に整えてご利用ください。
>
> また、GRAPHY は IME への登録を自動化しません。OS・IME のバージョンによって登録方法が
> 異なり、安全・確実に行うため**手動での登録**をお願いしています。以下の手順に従って一度だけ
> 登録すれば、以降はレポート入力中に通常の変換操作で医療用語が候補に表示されます。

対象 IME:

- **Windows — Microsoft IME(MS-IME)**
- **Windows — ATOK**
- **Ubuntu — Mozc**(ibus-mozc / fcitx5-mozc)
- **macOS — 日本語入力(Apple 標準)**(ATOK / Google 日本語入力をお使いの場合は該当章を参照)

> ⚠️ 画面の名称・メニュー位置は IME のバージョンにより異なる場合があります。本書と表示が
> 異なるときは、各 IME の「ユーザー辞書」「単語の一括登録」「辞書ツール」に相当する機能を
> お探しください。

---

## 1. 用意する辞書ファイル

GRAPHY は辞書データを**同梱しません**。お使いの IME に合わせて、**「よみ(ひらがな)→
表記(漢字)」の対応表**を記したファイルをご自身でご用意ください。公開されている医療用語辞書
や、自施設で作成した用語リストを、下表の形式に整えて使用します。

> ファイル名は任意です。本書では説明のため、以下の例の名前を使います。

| 対象 IME | 用意するファイル(例) | 文字コード | 区切り |
|---|---|---|---|
| Microsoft IME | `medical-msime.txt` | Unicode(UTF-16LE) | タブ |
| ATOK | `medical-atok.txt` | Unicode または Shift_JIS | タブ |
| Mozc | `medical-mozc.tsv` | UTF-8 | タブ |
| Apple 日本語入力(macOS) | `medical-macos.plist` | UTF-8 | (property list) |

書式の詳細と記入例は**付録(セクション 7)**を参照してください。少数の用語であれば、付録の
書式に従ってテキストエディタで直接作成することもできます。

---

## 2. Windows — Microsoft IME(MS-IME)への登録

MS-IME には「ユーザー辞書ツール」が用意されており、テキストファイルを一括で取り込めます。

### 2-1. ユーザー辞書ツールを開く

1. 画面右下の通知領域にある **入力モード表示(「あ」/「A」)を右クリック**します。
2. メニューから **「単語の追加」** または **「ユーザー辞書ツール」** を選びます。
   - 「単語の追加」しか出ない場合は、その画面の **「ユーザー辞書ツール」** ボタンから開きます。

> **Windows 11 の新しい MS-IME** でメニューが見つからない場合:
> 「設定 > 時刻と言語 > 言語と地域 > 日本語 > 言語のオプション > Microsoft IME >
> 全般」を開き、必要に応じて **「以前のバージョンの Microsoft IME を使う」** を一時的に
> オンにすると、従来のユーザー辞書ツールを利用できます。登録後は元に戻しても辞書は残ります。

### 2-2. テキストファイルから一括登録する

1. ユーザー辞書ツールのメニュー **「ツール(T)」 → 「テキスト ファイルからの登録(T)」** を選びます。
2. ファイル選択ダイアログで **`medical-msime.txt`** を指定します。
3. 「登録に成功しました」「○○語を処理しました」と表示されれば完了です。

> 文字化け・登録失敗が起きる場合は、ファイルの文字コードが原因のことがあります。MS-IME の
> テキスト辞書は **Unicode(UTF-16LE)** を推奨します。うまくいかない場合は、付録の書式に従い、
> メモ帳で「**名前を付けて保存 → 文字コード: Unicode**」で保存し直してから再度お試しください。

## 3. Windows — ATOK への登録

ATOK では「辞書ユーティリティ」の一括登録機能で、単語ファイルをまとめて取り込めます。

1. 通知領域の **ATOK パレット**(または ATOK メニュー)から **「辞書メンテナンス」 →
   「辞書ユーティリティ」** を開きます。
2. **「一括処理」タブ**(または「ツール > 単語の一括処理」)を選びます。
3. **「単語ファイルから辞書に単語を登録する」** を選択します。
4. 「単語ファイル」に **`medical-atok.txt`** を指定します。
5. 登録先の辞書(通常は **標準辞書(ATOK 用)** またはユーザー辞書)を選び、**「実行」** します。
6. 処理結果(登録件数・エラー件数)を確認して完了です。

> 登録先を専用のユーザー辞書に分けておくと、後で**まとめて削除・更新**しやすくなります
> (「辞書ユーティリティ」で新しいユーザー辞書を作成 → そこへ登録)。

---

## 4. Ubuntu — Mozc への登録

Mozc には「辞書ツール(Dictionary Tool)」があり、TSV ファイルをインポートできます。

### 4-1. 辞書ツールを開く

次のいずれかの方法で開きます。

- **入力メソッドのメニューから:** 画面上部(または下部)のキーボード/IME インジケーターを
  クリックし、**「ツール」 → 「辞書ツール」** を選びます。
  - ibus-mozc / fcitx5-mozc いずれも同様のメニューがあります。
- **コマンドから(メニューに無い場合):** 端末で次を実行します。

  ```bash
  /usr/lib/mozc/mozc_tool --mode=dictionary_tool
  ```

  (ディストリビューションにより `/usr/lib/mozc/` のパスが異なることがあります。
  見つからない場合は `dpkg -L mozc-utils-gui | grep mozc_tool` で場所を確認してください。
  `mozc-utils-gui` パッケージが未インストールなら `sudo apt install mozc-utils-gui` を実行します。)

### 4-2. TSV ファイルをインポートする

1. 辞書ツール左側で、インポート先の辞書を選びます。専用辞書を作る場合は **「管理」ボタン →
   「新規辞書にインポート…」** を選びます(既存辞書に追加するなら **「選択した辞書にインポート…」**)。
2. ファイル選択で **`medical-mozc.tsv`** を指定します。
3. 形式は **「Mozc 形式(タブ区切り)」** を選び、**インポート**を実行します。
4. 登録件数を確認して、辞書ツールを閉じます。

> 反映されない場合は、いったんログアウト/ログイン、または
> `ibus restart`(ibus の場合)で IME を再起動してください。

---

## 5. macOS — 日本語入力(Apple 標準)への登録

macOS 標準の日本語入力では「ユーザ辞書」に property list(`.plist`)ファイルをドラッグして
一括登録します。

### 5-1. ユーザ辞書を開く

次のいずれかで開きます。

- メニューバーの**入力メニュー(「あ」または「A」)をクリック → 「ユーザ辞書を編集…」**。
- または **アップルメニュー > システム設定 > キーボード >(テキスト入力)> ユーザ辞書**。
  - macOS のバージョンにより「**システム環境設定 > キーボード > ユーザ辞書**」の場合があります。

### 5-2. plist ファイルを読み込む

1. ユーザ辞書の一覧ウィンドウに、**`medical-macos.plist`** を**ドラッグ&ドロップ**します。
2. 確認が表示されたら追加を許可します。よみ(`shortcut`)と単語(`phrase`)の対が一括登録されます。

> macOS のユーザ辞書は「**よみを入力すると変換候補に単語が出る**」方式です。日本語入力中に
> よみ(ひらがな)を入力すると、登録した医療用語が候補に表示されます。
>
> **ATOK for Mac / Google 日本語入力(Mac)** をお使いの場合は、本章ではなく次に従ってください。
> - ATOK for Mac → **第 3 章(ATOK)** の手順に準じ、`medical-atok.txt` を取り込む。
> - Google 日本語入力(Mac)→ **第 4 章(Mozc)** と同じ辞書ツールで `medical-mozc.tsv` を取り込む。

---

## 6. 登録できたかの確認

1. テキストエディタや GRAPHY のレポート入力欄を開きます。
2. 医療用語の**よみをひらがなで入力**し、変換(スペースキー)します。
   - 例: 「はいきしゅ」→「肺気腫」、「すりがらすいんえい」→「すりガラス陰影」 など
   - (実際に変換できる語は、登録した辞書ファイルの内容によります)
3. 候補に医療用語が表示されれば登録成功です。

---

## 7. 付録:辞書ファイルの書式

辞書を自施設で追加・編集する場合の参考です。テキスト系はいずれも **1 行 1 語**、列の区切りは
**タブ文字**です(macOS は property list)。

### 7-1. Microsoft IME(テキスト辞書)

```
よみ<TAB>語<TAB>品詞
```

- 文字コード: **Unicode(UTF-16LE)** を推奨。
- 品詞は **「名詞」** を基本とします(固有名詞は「固有名詞」)。
- 行頭が `!` の行はコメントとして扱われます。
- 例:

  ```
  はいきしゅ	肺気腫	名詞
  すりがらすいんえい	すりガラス陰影	名詞
  じょうみゃくけっせんしょく	静脈血栓塞栓症	名詞
  ```

### 7-2. ATOK(単語ファイル)

```
よみ<TAB>単語<TAB>品詞
```

- 文字コード: お使いの ATOK が読み取れる **Unicode** または **Shift_JIS**。
- 品詞は ATOK の品詞名(「名詞」「固有名詞」など)。
- 例:

  ```
  はいきしゅ	肺気腫	名詞
  すりがらすいんえい	すりガラス陰影	名詞
  ```

### 7-3. Mozc(TSV)

```
よみ<TAB>単語<TAB>品詞<TAB>コメント
```

- 文字コード: **UTF-8**、改行は LF。
- 「コメント」列は省略可(ICD コードや出典の記録に利用可)。
- 品詞は Mozc の品詞名(「名詞」など)。
- 例:

  ```
  はいきしゅ	肺気腫	名詞	J43
  すりがらすいんえい	すりガラス陰影	名詞	
  ```

### 7-4. macOS(Apple ユーザ辞書 / property list)

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<array>
  <dict>
    <key>phrase</key><string>肺気腫</string>
    <key>shortcut</key><string>はいきしゅ</string>
  </dict>
  <dict>
    <key>phrase</key><string>すりガラス陰影</string>
    <key>shortcut</key><string>すりがらすいんえい</string>
  </dict>
</array>
</plist>
```

- `shortcut` = よみ(ひらがな)、`phrase` = 表記(漢字)。文字コードは **UTF-8**。
- `<array>` の中に `<dict>` を 1 語ぶんずつ並べます。

## 8. 辞書の更新・削除

- **更新**: 辞書ファイルが新しくなったら、同じ手順で再度インポートしてください
  (専用ユーザー辞書に登録しておくと差し替えが容易です)。
- **削除**: 各 IME のユーザー辞書ツール/辞書ユーティリティ/辞書ツールで、対象の辞書または
  単語を選んで削除します。専用辞書にまとめておくと一括削除できます。

---

## 9. 困ったとき(トラブルシュート)

| 症状 | 対処 |
|---|---|
| インポートで文字化けする | ファイルの文字コードを各 IME の推奨(MS-IME: Unicode / Mozc: UTF-8)に合わせて保存し直す。 |
| 列がずれて登録される | 区切りが**タブ**になっているか確認(スペースや全角空白になっていないか)。 |
| 登録したのに変換に出ない | IME を再起動(Windows: 入力切替/再ログイン、Ubuntu: `ibus restart`)。登録先辞書が**有効**になっているか確認。 |
| メニューに辞書ツールが無い(Win11 新 MS-IME) | 「以前のバージョンの Microsoft IME を使う」を一時的にオンにして登録。 |
| Mozc に辞書ツールが無い | `sudo apt install mozc-utils-gui` を実行後、`/usr/lib/mozc/mozc_tool --mode=dictionary_tool` で起動。 |
| ドラッグしても追加されない(Mac) | 入力メニューの「ユーザ辞書を編集…」のウィンドウに直接ドロップ。反映後、入力メニューを切り替えるか再ログイン。 |

---

*本書は手動登録の手順を示すものです。表示名称・パスは OS / IME のバージョンにより前後する
ことがあります。実機の表示に合わせて読み替えてください。*
